# SMMT × NEXO 공동구매 랜딩 페이지

수학 강사 커뮤니티 'SMMT'와 전자칠판 브랜드 'NEXO'의 콜라보레이션 공동구매 랜딩 페이지입니다.

## 기술 스택

- React 18
- Vite
- Tailwind CSS
- Framer Motion

## 설치 및 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build
```

## 주요 기능

- 반응형 디자인 (모바일 퍼스트)
- 스크롤 애니메이션
- FAQ 아코디언
- 상담 신청 폼 (CRM 연동 준비)
- Sticky 헤더

## 디자인 컨셉

- **색상**: Deep Navy (#0f172a), Vibrant Orange (#f97316)
- **폰트**: Noto Sans KR (한글), Montserrat (영문/숫자)
- **톤**: 신뢰감, 세련됨, 기술적 진보, 미니멀리즘
